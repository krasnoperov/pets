# Ролик про Кабанчика

Исходники вертикального ролика `1080×1920`, собранного в Remotion.

Готовый рендер: [`kabanchik-tiktok.mp4`](./kabanchik-tiktok.mp4).

Обложка для вертикальных площадок:
[`kabanchik-cover.png`](./kabanchik-cover.png).

## Запуск

```bash
pnpm install
pnpm studio
```

## Рендер

```bash
pnpm render
```

Готовый файл будет записан в `outputs/kabanchik-video.mp4` от корня
репозитория.

В `public/audio` лежат использованные голосовые дорожки и звуки, а в
`public/frames` — покадровые анимации маскота для ролика.
